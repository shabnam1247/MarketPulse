# MarketPulse

## Stock Market Intelligence & Web Scraping Dashboard

MarketPulse is a Flask-based stock market web scraping and analytics project.

## Features

- Professional dashboard
- Stock market watchlist
- Stock search
- Individual stock details
- Historical price chart
- Market analytics
- Gainers
- Losers
- CSV export
- Excel export
- Dark mode
- Responsive UI
- Python web scraping
- Pandas data processing
- Flask backend
- Chart.js visualization

## Technologies

Flask

BeautifulSoup
